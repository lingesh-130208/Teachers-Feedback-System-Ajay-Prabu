TEACHERS FEEDBACK SYSTEM - EXECUTION STEPS
============================================

Prerequisites:
- JDK 17 or later installed
- Apache Maven 3.6+ installed
- MySQL Server 8.0+ installed and running

STEP 1: Set Up MySQL Database
-----------------------------
1. Open MySQL Command Line or MySQL Workbench
2. Execute the schema file:

   mysql -u root -p database/schema.sql

   This will:
   - Create the TeachersFeedbackSystem database
   - Create Student, Faculty, Admin, and Feedback tables
   - Insert demo accounts with SHA-256 hashed passwords

STEP 2: Set Environment Variables (Windows CMD)
------------------------------------------------
Open a new Windows Command Prompt and run:

   set TFS_DB_URL=jdbc:mysql://localhost:3306/TeachersFeedbackSystem?useSSL=false&serverTimezone=UTC
   set TFS_DB_USER=root
   set TFS_DB_PASSWORD=your_mysql_password

Replace "your_mysql_password" with your actual MySQL root password.

For Linux/Mac, use:

   export TFS_DB_URL=jdbc:mysql://localhost:3306/TeachersFeedbackSystem?useSSL=false&serverTimezone=UTC
   export TFS_DB_USER=root
   export TFS_DB_PASSWORD=your_mysql_password

STEP 3: Compile the Project
----------------------------
In the project root directory, run:

   mvn clean compile

This will download dependencies (MySQL Connector/J 9.1.0) and compile
the Java source files.

STEP 4: Run the Application
----------------------------
To run the application:

   mvn exec:java

This will start the Teachers Feedback System console application.

STEP 6: Using the Application
------------------------------
After logging in:

STUDENT:
- List all faculty members
- Submit feedback for each faculty (1-5 rating, optional comments)
- Only one feedback per faculty allowed

FACULTY:
- View anonymized average feedback report
- See total feedback count and average rating

ADMIN:
- Add new students
- Add new faculty members
- List all students
- List all faculty
- View all faculty reports
